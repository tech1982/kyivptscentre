АКССЕССУАРЫ ДЛЯ ОБЩЕГО ОБОРУДОВАНИЯ СИСТЕМ ПНЕВМОПОЧТЫ:

СПЕЦИАЛИЗИРОВАННЫЕ КАБЕЛЬНЫЕ КАНАЛЫ

Специализированные кабельные каналы используются в основном для систем пневмопочты, предназначенных для передачи наличных денег, и применяются для подвода коммуникационных кабелей к кассовым столам и закрепления станций пневмопочты при отсутствии жесткой поверхности для их закрепления в вертикальном положении. Это относится к станциям Diana, Centurion и Orion.

Каналы по умолчанию комплектуются пластиковыми хомутами для закрепления станций, крепежными принадлежностями для крепления каналов к полу и кассовым столам, а также могут комплектоваться номерными светильниками для касс и кожухами для закрытия корпусов станций.

Корпус каналов выполнен из листовой стали с порошковым покрытием и имеет перфорированные заготовки для вывода кабелей под кассовыми столами. Цвет порошкового покрытия определяется заказчиком.

Внутри канала размещен перфорированный пластиковый кабельный канал для размещения системных кабелей пневмопочты и изоляции их от других типов кабелей.

Габаритные размеры одной секции: 2000Х120Х85 мм. Возможно изготовление каналов с размерами, в соответствии с пожеланиями заказчика.

Стыковка секций производится с использованием стыковочного замка, закрепляемого с использованием заклепок, обеспечивая при этом надежную фиксацию секций.


СВЕТОЗВУКОСИГНАЛИЗАТОР ASG1.4

Светозвукосигнализатор ASG1.4 применяется для световой и звуковой сигнализации при отправке капсул c передающих станций систем пневмопочты MP10.000, а также для сигнализации о прибытии капсул на станциях типа Orion, Centurion, DRT и DRT Front и др..

Кроме того, данное устройство может применяться в любых устройствах, в которых необходима сигнализация о каких-либо событиях.

Основные параметры:

1. Количество звуковых тонов – 3;
2. Режимы работы:
а) только световая сигнализация;
б) световая + звуковая сигнализация;
2. Потребляемый ток:
а) в режиме только световой сигнализации – 45 мА;
б) в режиме световой + звуковой сигнализации (50 % громкость сигнала) – 100 мА;
в) в режиме световой + звуковой сигнализации (100 % громкость сигнала) – 200 мА.

5. КОМБИНИРОВАННЫЙ ЭКРАНИРОВАННЫЙ КАБЕЛЬ В МЯГКОЙ ОБОЛОЧКЕ KS118 POLYFLEX (2x2x0,22 + 3x2,5)

1. Поливинилхлоридная изоляционная оболочка. Наружный диаметр 12 мм, минимальная толщина стенки оболочки - 0,75 мм, цвет серый.
2. Дополнительная целлофановая изоляция;
3. Медные многожильные проводники шины питания. Поперечное сечение медной жилы проводников - 2,5 мм2, наружный диаметр проводников в изоляции – 3,5 ±0,1 мм;
4. Наружная оболочка шины данных;
5. Фольгированный экран;
6. Экранный провод;
7. Дополнительная целлофановая изоляция;
8. Медные многожильные проводники шины данных. Две витые пары с сечением проводников 0,22 мм2. Наружный диаметр проводников в изоляции - 1±0,05 мм;

Основные параметры кабеля KS118:

1. Максимальное сопротивление проводников при t=20°C:
а) для проводников шины данных (сечение 0,22 мм2) – 85 Ом/км;
б) для проводников шины питания (сечение 2,5 мм2) - 8,0 Ом/км;

2. Напряжение пробоя:
а) провод/провод - 2,0 КВ эфф./мин;
б) провод/экран - 0,5 КВ эфф./мин.;

3. Паразитная емкость на частоте 1kГц - пара: не менее 230 nФ/км;

4. Сопротивление изоляции на частоте 1kГц - пара: не более 2 ГОм/км;

5. Рабочий диапазон температур:
а) для эксплуатации от -30°C до +70°C
б) при монтаже от -5°C до +50°C;

6. Вес - 130 г/м;

7. Поставочные характеристики: бухты по 100 м, или катушки TH со стандартной длиной кабеля 400 м;

8. Особые указания по эксплуатации: не устойчив к ультрафиолетовому облучению!

9. Область применения: любое оборудование с использованием стандартных промышленных протоколов RS232, RS422 и RS485.

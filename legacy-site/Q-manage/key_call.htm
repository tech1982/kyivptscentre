КЛАВИАТУРЫ ВЫЗОВА QN-KC02, QN-KC03, KB23 QC-KB-001, QC-SWKB, QN-KC04

Клавиатуры вызова QN-KC02, QN-KC03, KB23 QC-KB-001, QC-SWKB и QN-KC04 используются для первичного, либо повторного вызова клиентов к обслуживанию, для помещения клиентов в список ожидания, для перенаправления клиента к очередной услуге или к другой стойке обслуживания, а также для завершения работы с клиентом. Клавиатуры вызова могут быть как как специализированными (QN-KC02, QN-KC03, KB23 QC-KB-001), выполненными в виде отдельных пультовых блоков, так и программными (QC-SWKB и QN-KC04), использующими ОС Windows. Назначение клавиш у программных и специализированных клавиатур - равнозначно.
Перечисленные ниже специализированные клавиатуры могут быть использованы в системах Q-Net Standard, Q-Net Pro, QControl Neo, QControl Paleo и QControl Mino. Программные клавиатуры могут быть использованы в системах Q-Net Pro и QControl Paleo.

Программная клавиатура QN-KC04

Клавиатуры вызова клиентов QN-KC02, QN-KC03, KB23 QC-KB-001, QC-SWKB и QN-KC04 обеспечивают:

- авторизацию операторов при входе в систему (ввод логина и пароля);
- приглашение клиента к обслуживанию;
- неограниченное количество повторных вызовов клиентов при их неприбытии для обслуживания;
- перенаправление клиентов к другой стойке обслуживания (оператору);
- перенаправление клиентов к другой услуге на текущей стойке обслуживания;
- помещение клиентов в список ожидания;
- вызов клиентов из списка ожидания;
- индикацию количества клиентов, ожидающих предоставления услуг, для данной стойки обслуживания;
- отображение информации о количестве клиентов в списке ожидания (только для программных клавиатур);
- индикацию номера обслуживаемого клиента;
- автоматическое приглашение клиентов к обслуживанию (только для программных клавиатур);
- закрытие работы с клиентом по окончании предоставления услуг, либо по неприбытию клиента;
- выход оператора из системы;

Распределители сигналов:

Распределители сигналов служат для объединения коммуникационных линий от устройств системы, а также для подачи локального дополнительного питания на устройства системы.

Доступны распределители сигналов двух типов: QC-D8-001 (8 портов ввода-вывода) и QN-OE01 (10 портов ввода-вывода).


Системные источники питания:

Системные источники питания обеспечивают напряжение постоянного тока 12 В при токах нагрузки, зависящих он состава системы.
Источники питания могут общими для системы - для питания всех устройств, либо локальными - для питания отдельных устройств системы (например: суммирующих дисплеев с высотой индикаторов 100 мм).

Доступны следующие типы системных источников питания: QN-OB01-1.0 A, QN-OB02-3.0 A, QN-OB03-7.2 A, QN-OB04-8.0 A, QC-NN-PSUPAT-10.0 A.

Термобумага для термопринтеров:

Термобумага используется для печати талонов клиентов посредством термопринтеров регистраторов клиентов.

Доступны следующие типоразмеры термобумаги: QC-NN-TT 79/110 (для кнопочных регистраторов клиентов системы QControl), QC- NN-TT 79/150 (для сенсорных регистраторов клиентов системы QControl), QN-0A01 58/70 (для регистраторов системы QNet Basic и QNet Basic Plus) и QN-0A02 80/80 (для регистраторов системы QNet Standard и QNet Pro) .


Стойки для вызывных дисплеев:

Стойки используются для крепления вызывных дисплеев на элементах мебели обслуживающей компании, а также для скрытого подвода соединительных кабелей к вызывным дисплеям.

Доступны следующие типоразмеры стоек: QC-DP3-400 мм, QC-DP3-790 мм, QN-OD01-500 мм.
